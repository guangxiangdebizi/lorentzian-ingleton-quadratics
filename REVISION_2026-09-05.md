# Explicit quadratic floor: 2026-09-05 revision

## Mathematical change

The main theorem now states

```text
476656^(-5) <= c_2^* <= (-107 + 51 sqrt(17))/128.
```

The full proof is in `paper/main.tex`, not delegated to an external note:
16 membership atoms, exact two-clone polarization, the row-sum spherical
representation, minimum-bottleneck ultrametric distortion, an explicit
Laurent tree realization, common-module Ingleton, and a five-factor sum/max
comparison. The actual finite coefficients are controlled; no compactness
argument or previous non-effective floor is used to obtain the number.

The result applies to all nonnegative Lorentzian quadratics. For rational
input the admissibility gate and finite comparator use exact rational
arithmetic. The real-coefficient theorem does not imply an exact oracle for
arbitrary black-box real numbers. The old degeneration proof is retained as
an alternative qualitative proof. The upper bound is unchanged, the new
lower bound is not claimed sharp, and no new literature-priority claim or
result for arbitrary Lorentzian quartics is made.
